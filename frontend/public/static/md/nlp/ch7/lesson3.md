<h1 style="margin: 0 0 12px 0; font-size: 28px; font-weight: 900; letter-spacing: -0.5px; color: #0f172a;">GPT의 핵심 아이디어 "다음 단어를 예측하라"</h1>

<h2 style="margin-top: 0; color: #0f172a; font-weight: 900; letter-spacing: -0.4px;">🎯 GPT가 학습하는 단 하나의 규칙</h2>

<p style="line-height: 1.8; color: #334155; font-size: 15px;">GPT의 학습 방식은 놀라울 정도로 단순합니다.</p>

<div style="background-color: #eef7ff; border: 2px solid #c2e4ff; padding: 15px 17px; border-radius: 12px; font-size: 15px; color: #1681c4; font-weight: 900; text-align: center; margin: 14px 0;">
"지금까지 나온 단어들을 보고, 다음에 올 단어를 맞춰라"
</div>

<div style="background-color: #fff3eb; border: 2px solid #ffd0b0; padding: 13px 16px; border-radius: 12px; font-size: 14px; color: #334155; line-height: 1.8;">
<span style="color: #FF6B00; font-weight: 900;">💡</span> 이게 전부입니다. 수십억 개의 문장으로 이 한 가지 과제를 반복하면서 GPT는 <b style="color:#FF6B00;">언어의 패턴, 문법, 의미, 상식</b>까지 학습하게 됩니다.
</div>

</div>

<h2 style="margin-top: 0; color: #0f172a; font-weight: 900; letter-spacing: -0.4px;">📖 비유로 이해하기: 빈칸 채우기 달인</h2>

<div style="background-color: #f8fafc; border: 2px solid #e2e8f0; padding: 13px 17px; border-radius: 12px; font-size: 15px; color: #0f172a; font-weight: 700; text-align: center; margin-bottom: 16px;">
"오늘 날씨가 맑아서 기분이 <span style="color:#1681c4; background:#fff; border:1px solid #c2e4ff; padding:2px 10px; border-radius:6px;">___</span>"

<p style="line-height: 1.8; color: #334155; font-size: 15px; margin-bottom: 14px;">
우리는 자연스럽게 "좋다", "상쾌하다" 같은 단어가 떠오릅니다. 수천 권의 책을 읽은 사람이라면 더 다양하고 자연스러운 단어를 떠올리겠죠.
</p>

<div style="background:#eef7ff; border:2px solid #c2e4ff; padding:13px 16px; border-radius:12px; font-size:14px; color:#334155; line-height:1.8;">
<span style="color:#1681c4; font-weight:900;">🤖 GPT도 똑같습니다.</span><br>
인터넷에 있는 엄청난 양의 글을 읽으면서 <b style="color:#1681c4;">"이런 상황에서는 보통 이런 단어가 온다"</b>는 패턴을 익힙니다.
</div>
